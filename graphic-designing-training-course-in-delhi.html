Overview

What is Graphic Designing?

Graphic Designing is the discipline of finding out whether software does what it should — and what it does when things go wrong. It covers everything from checking a requirement for gaps, to designing and running test cases, to automating regression suites that run every night.

Testing has two halves. Manual testing relies on human judgement to explore features, find usability issues and validate business rules. Automation testing turns repeatable checks into code so they can run on every build. Teams need both, and the most employable testers can do both. This programme is the complete path: it starts where a fresher starts and ends where a junior SDET is expected to be — able to design tests, report defects, query databases, test APIs and maintain a Selenium framework in CI.

What a junior QA engineer actually does in a sprint

Recruiters in Delhi ask scenario questions based on this cycle. The course walks you through it end to end.

  • Sprint planning: read user stories, ask clarifying questions, estimate testing effort
  • Test design: write scenarios and cases, decide which ones to automate
  • Execution: test new features manually, run API checks and the automated regression suite
  • Defect management: log, retest and close bugs in JIRA; join triage with developers
  • Regression and sign-off: confirm nothing old broke, share test metrics, support release
  • Retrospective: suggest one process or automation improvement for the next sprint

Deep dive — API testing block

  • Postman: collections, environments, variables, test scripts and the collection runner
  • REST Assured with BDD syntax: status, body and header assertions
  • Extracting tokens and chaining authenticated requests
  • Payload-driven tests with data from Excel; JSON schema validation

Deep dive — Selenium hybrid framework

  • WebDriver setup, locators and synchronisation with implicit and explicit waits
  • Page Object Model with TestNG annotations and data providers
  • External test data from Excel, XML and property files
  • Running the suite from Jenkins and emailing reports to the team
